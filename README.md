# School ERP SaaS

A multi-tenant School Enterprise Resource Planning (ERP) Software as a Service (SaaS) application.

## Directory Structure

```text
school-erp-saas/
├── backend/            # Backend API / Services
├── frontend/           # Frontend Web Application
├── database/           # Database migrations, seeds, and schemas
├── docker/             # Dockerfiles and container configurations
├── deployment/         # Deployment scripts and configuration files
├── docs/               # Project documentation
├── infrastructure/     # Infrastructure as Code (Terraform, Ansible, etc.)
├── scripts/            # Utility scripts (setup, backup, migration, etc.)
├── testing/            # End-to-end and integration tests
└── .github/            # GitHub Actions CI/CD workflows and issue templates
